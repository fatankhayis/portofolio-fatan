My Story

Perkenalan

Saya Fatan Khayis Khabibullah, mahasiswa D3 Sistem Informasi yang fokus pada pengembangan web dan aplikasi. Selama studi dan proyek pribadi saya telah membangun beberapa aplikasi berbasis web maupun apilkasi android, mulai dari landing page statis hingga sistem CRUD sederhana dengan menggunakan HTML, CSS, JavaScript serta backend dengan PHP (Laravel) ketika diperlukan. Lalu saya menggunakan flutter untuk membangun aplikasi android yang lebih responsif serta memiliki user interface yang menarik.

Saya memiliki ketertarikan khusus dalam merancang antarmuka yang intuitif dan responsif, memastikan pengalaman pengguna yang konsisten di berbagai perangkat. Saya juga berpengalaman melakukan integrasi API, membuat alur autentikasi sederhana, serta mengoptimalkan performa halaman agar lebih cepat dimuat.

Saat ini saya aktif mengumpulkan portofolio proyek di bagian Projects pada situs ini. Jika Anda ingin melihat contoh kerja atau mendiskusikan peluang kolaborasi, silakan hubungi saya melalui email atau tautan sosial di bagian Contact. Saya terbuka untuk proyek freelance dan kerja magang.
